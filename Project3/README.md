# 🍷 Wine Quality Analysis

## 📌 Project Overview

Wine Quality Analysis is a data analysis project that explores the factors affecting wine quality using Python. The project uses data cleaning, exploratory data analysis (EDA), statistical analysis, correlation analysis, and visualization to understand the characteristics of wine quality.

## 🎯 Objective

The main objective of this project is to explore the factors that influence wine quality and identify relationships between different chemical properties and wine quality.

## 📂 Dataset

The dataset contains information about different properties of wine, such as:

- Fixed acidity
- Volatile acidity
- Citric acid
- Residual sugar
- Chlorides
- Free sulfur dioxide
- Total sulfur dioxide
- Density
- pH
- Sulphates
- Alcohol
- Quality

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Jupyter Notebook

## 🔍 Project Steps

### 1. Data Import

Loaded the wine quality dataset using Pandas.

### 2. Data Cleaning

- Checked missing values
- Checked duplicate records
- Checked data types
- Cleaned the dataset
- Prepared the data for analysis

### 3. Exploratory Data Analysis

Performed EDA to understand the structure and distribution of the dataset.

### 4. Descriptive Statistics

Calculated:

- Mean
- Median
- Minimum
- Maximum
- Standard deviation

### 5. Correlation Analysis

Created a correlation matrix to understand relationships between wine characteristics and quality.

### 6. Data Visualization

Created visualizations such as:

- Histograms
- Bar charts
- Box plots
- Scatter plots
- Correlation heatmap

## 💡 Key Insights

The analysis helps identify which wine characteristics have stronger relationships with wine quality.

## ✅ Conclusion

This project demonstrates how Python can be used to clean, explore, analyze, and visualize wine quality data. The results provide useful insights into the factors associated with wine quality.
