# 💎 Diamond Price Analysis

## 📌 Project Overview

Diamond Price Analysis is a data analysis project that explores how different characteristics of diamonds influence their prices. The project uses Python to clean, analyze, visualize, and understand relationships between diamond features and price.

## 🎯 Objective

The main objective of this project is to analyze diamond characteristics and identify the factors that have an important relationship with diamond prices.

## 📂 Dataset

The dataset contains information about diamonds, including:

- Carat
- Cut
- Color
- Clarity
- Depth
- Table
- Price
- X
- Y
- Z

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Jupyter Notebook

## 🔍 Project Steps

### 1. Data Import

Loaded the diamond dataset using Pandas.

### 2. Data Cleaning

- Checked missing values
- Checked duplicate records
- Checked data types
- Identified invalid values
- Prepared the dataset for analysis

### 3. Exploratory Data Analysis

Performed EDA to understand numerical and categorical features.

### 4. Statistical Analysis

Calculated important statistical measures such as:

- Mean
- Median
- Minimum
- Maximum
- Standard deviation

### 5. Outlier Detection

Detected unusual values using statistical methods and box plots.

### 6. Feature Analysis

Analyzed relationships between diamond characteristics and price.

### 7. Data Visualization

Created visualizations such as:

- Histograms
- Bar charts
- Box plots
- Scatter plots
- Correlation heatmap

## 💡 Key Insights

The analysis helps understand how characteristics such as carat, cut, color, and clarity are related to diamond prices.

## 📊 Business Insights

Understanding diamond price patterns can help businesses:

- Analyze pricing factors
- Understand customer preferences
- Compare diamond characteristics
- Support pricing decisions

## ✅ Conclusion

This project demonstrates how Python and data analysis techniques can be used to clean, explore, visualize, and analyze diamond pricing data.
